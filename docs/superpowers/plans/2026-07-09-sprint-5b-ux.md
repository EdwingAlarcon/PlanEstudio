# Sprint 5B UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Polish onboarding copy, route guidance, simulator context, mobile navigation clarity, and add a practical "Como usar esta plataforma" page.

**Architecture:** Keep changes within the existing Next.js App Router and local data modules. Use `professional-routes.ts` as the source of truth for route status and next-route CTAs, and use existing shadcn/ui components for visual consistency.

**Tech Stack:** Next.js 15 App Router, TypeScript, Tailwind CSS, Vitest, Testing Library.

## Global Constraints

- All user-facing copy stays in Spanish.
- Preserve the existing Fluent/Power Platform visual language.
- Keep cards compact, responsive, and readable on mobile.
- Use tests first for data/contract changes.
- Run `npm run verify` before completion.
